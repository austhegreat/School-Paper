📐 RUMUS & KONSEP PENTING BAB 1 / KEY FORMULAE & CONCEPTS
• Bentuk Am: f(x) = ax2 + bx + c,   a ≠ 0
• Paksi Simetri: x = −b/2a
• Titik Minimum: a > 0 (Bentuk ∪)
• Titik Maksimum: a < 0 (Bentuk ∩)
• Pintasan-y: Koordinat (0, c)
• Lebar Graf: |a| bertambah ⇒ Graf semakin sempit
• Punca Kuadratik: x = −b ± √[b2 − 4ac]/2a
• Pembezalayan: b2 − 4ac > 0 (2 punca), = 0 (1 punca), < 0 (tiada punca)
• Bentuk dari Punca: x2 − (HTP)x + (HDP) = 0
• Titik Simetri Punca: x = (x1 + x2)/2
